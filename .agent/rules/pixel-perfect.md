# Design System: Jake Smith's Resume

## 1. Colors

- **Primary Background**: `#0F0F0F` (Dark mode background, almost black)
- **Accent/Card Background**: `#1A1A1A` (Used for project cards and secondary containers)
- **Primary Text**: `#FFFFFF` (Pure white for main headings and titles)
- **Secondary Text**: `#A1A1A1` (Muted light gray for body copy, labels, etc.)

## 2. Typography

- **Font Family**: Primary sans-serif is **Inter**
- **Headings**: Large, bold/semi-bold weight for section titles
- **Body Text**: Standard weight (16-18px) with generous line height

## 3. Layout Structure

- **General Layout**: Modern, minimal two-column structure
- **Navigation**: Sticky header
- **Sections**: Split into two columns (Left: Section title, Right: Content modules)
- **Container**: Centered, max-width around 1000px

## 4. Spacing Conventions

- **Section Padding**: 100px - 120px between major sections
- **Internal Spacing**: 20px - 40px between content blocks
- **Margins**: ~10% - 15% of viewport width
